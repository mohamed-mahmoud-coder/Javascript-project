# 🧠 Quiz App

A simple, interactive quiz application built with HTML, CSS, and Vanilla JavaScript. It dynamically fetches 5 random questions from a larger pool, provides instant feedback, and tracks your final score!

## ✨ Features
* 🎲 **Randomized Questions:** Selects 5 random questions per session.
* ⚡ **Instant Feedback:** Answers are immediately highlighted as correct (green) or incorrect (red).
* 📊 **Score Tracking:** Calculates your final score and percentage.
* 🚀 **Smooth UI:** Transitions smoothly between start, quiz, and result screens without reloading the page.

## 🛠️️ Built With
* HTML5
* CSS3
* Vanilla JavaScript (DOM manipulation, Array methods)

## 🚀 How to Run
No installation or local server required! 
1. Clone this repository to your local machine.
2. Open the `index.html` file in any web browser.
3. Click "Start Quiz" and enjoy!
